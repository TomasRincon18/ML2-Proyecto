# Deck de sustentación

Abre `index.html` en el navegador. Es la versión actual del deck y funciona sin internet porque reveal.js y las imágenes están en la carpeta. `slides.pdf` queda como respaldo.

## Controles

- Flechas izquierda y derecha para avanzar.
- `F` para pantalla completa.
- `S` para ver las notas del presentador.
- `Esc` para salir de la vista general.

## Contenido

- 12 diapositivas.
- Imágenes en `assets/`.
- reveal.js local en `reveal/`.
- PDF de respaldo: `slides.pdf` (12 páginas).
- Guion y reparto: `guion.md`.

## Regenerar figuras

Desde `Entrega3`:

```bash
python src/build_slide_figures.py
```

El script escribe las figuras en `slides/assets/`.
